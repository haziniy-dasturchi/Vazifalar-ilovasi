# Yo'riqnoma suratlari

Bu papkaga qo'yiladigan fayllar yo'riqnomadagi tegishli bo'limda,
tushuntirish tepasida ko'rinadi. Fayl yo'q bo'lsa hech narsa
ko'rsatilmaydi — shuning uchun ularni ketma-ket qo'shib borish mumkin.

Nomlar aniq shunday bo'lishi kerak (`.png`):

| Fayl | Nima ko'rinishi kerak |
|---|---|
| `jarayonda.png` | "Jarayonda" sahifasi, bir nechta boshlangan ish bilan |
| `bugun.png` | "Bugun" sahifasi: kechikkan, bugungi va bajarilgan ishlar |
| `vazifa.png` | Vazifa oynasi ochiq holda (nom, izoh, sana, muhimlik, foiz) |
| `kalit-sozlar.png` | Nomga "Hisobot ertaga 9" yozilgan, belgilangan qismi rangli |
| `izoh.png` | Izohi bor vazifa ro'yxatda ko'rinib turgani |
| `papkalar.png` | Yon panel yoki papka sahifasi |
| `loyihalar.png` | Loyihalar sahifasi, uch guruh ko'rinib turgani |
| `hisobot.png` | Hisobot sahifasi, kartalar va papkalar holati |
| `topshiriqlar.png` | Topshiriqlar sahifasi, kelgan topshiriq kartasi |
| `offline.png` | Internet yo'q paytdagi qora chiziq va kutayotgan o'zgarishlar |

Tavsiya: telefon surati bo'lsa yaxshi (ilova ko'proq telefonda
ishlatiladi), kengligi 800–1200 px yetarli. Shaxsiy ma'lumot
(email, haqiqiy ismlar) ko'rinmasin.
